# DWES08-Django

Proyecto académico desarrollado durante el ciclo de Desarrollo de Aplicaciones Web (DAW) utilizando Django.

## Tecnologías utilizadas

- Python
- Django
- HTML y CSS
- SQLite
- django-allauth
- Google Calendar API

## Funcionalidades

- Gestión de eventos.
- Visualización del calendario de actividades.
- Reserva de plazas en eventos.
- Autenticación mediante Google.
- Integración con Google Calendar.

## Proyecto académico

Este proyecto fue desarrollado como parte del módulo de Desarrollo Web en Entorno Servidor (DWES).
